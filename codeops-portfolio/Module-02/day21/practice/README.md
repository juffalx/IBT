# Exercises

Six small, testable steps, each labelled in `js/script.js`:

1. Theme toggle — saved on change, restored on load via `localStorage`.
2. `save()` / `load()` helpers — stringify/parse with `try`/`catch`, guarding
   `null` and corrupt data.
3. Signup form — labelled name and phone inputs, submit button, error area.
4. On submit: `preventDefault`, trim values, validate name length and the
   Ethiopian phone regex.
5. First problem found is shown via `textContent`.
6. Valid entry saved as JSON, form cleared, signup count shown.

## Run it

Open `index.html` in a browser.
