Demo Script

  1. The problem: Addis Eats lets people browse an Ethiopian menu, build a cart, and order with a validated TeleBirr phone number.
  2. Live walkthrough: search a dish, add it to the cart, change the quantity, then complete checkout.
  3. One proud part: the whole app runs off one state object; every screen re-renders from it.
  4. One hard bug: cart clicks on the quantity number did nothing, because the id was read from the wrong element; fixed with closest("[data-id]").
