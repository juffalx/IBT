# pages

One page per exercise. `exercises.js` lists them in order and drives the navigation buttons in `App.jsx`.

| Page | Exercise |
| --- | --- |
| `ThemeContextPage` | 1. ThemeContext read from a deeply nested component |
| `UseFetchPage` | 2. `useFetch` used in two components |
| `ReducerTestPage` | 3. `cartReducer` called directly with plain objects |
| `StateToReducerPage` | 4. Three `useState` calls versus one `useReducer` |
| `CartProviderPage` | 5. `CartProvider` sharing items, dispatch and total |
| `MemoProviderPage` | 6. Memoised provider value |
| `MemoCallbackPage` | 7. `React.memo` with `useCallback` on the dish list |

Each page folder has its own README.
